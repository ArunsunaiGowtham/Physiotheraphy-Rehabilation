1. Introduction

Welcome to PhysioLife, a premier multipurpose commercial HTML5 website template engineered primarily for Physiotherapy & Rehabilitation Clinics, sports injury recovery centers, and healthcare practitioners, with built-in versatility for any service-based business.

The package includes over 25+ meticulously crafted HTML pages, a dedicated Patient Care Dashboard, an executive Clinic Admin Portal, an authentication suite, and native support for both Dark Mode and Right-to-Left (RTL) layouts.

3. Technology Stack

  • HTML5: Semantic elements, accessible ARIA attributes, structured metadata.
  • Bootstrap 5.3.3: Responsive 12-column grid, modals, dropdowns, tooltips.
  • Vanilla CSS3: Custom CSS variables (`variables.css`), glassmorphism, responsive breakpoints.
  • Font Awesome 6.5: Modern vector icons for medical, clinical, and dashboard navigation.
  • Chart.js 4.4: Responsive, interactive, dark/light adaptive charts for patients and admin.
  • Vanilla JavaScript (ES6+): Pure modular scripts without heavy jQuery dependencies.

4. Dark/Light & RTL Modes

PhysioLife features a built-in theme and direction engine in assets/js/theme.js. Preferences are automatically saved in the user's browser via localStorage.

Setting Default Theme or RTL in HTML

To force dark mode by default on any page, update the <html> tag:

<html lang="en" data-bs-theme="dark" dir="ltr">

To set Arabic or Hebrew (RTL) mode by default:

<html lang="ar" data-bs-theme="light" dir="rtl">

5. Changing Colors & Fonts

All brand colors, fonts, borders, and shadows are defined in assets/css/variables.css. To re-brand the template, simply modify the root CSS variables:

:root {
  /* Change Brand Primary Color */
  --primary: #0F766E;        /* Medical Teal */
  --primary-hover: #0D9488;
  
  /* Change Action Secondary Color */
  --secondary: #F97316;      /* Energy Amber/Coral */
  
  /* Change Fonts */
  --font-family-body: 'Plus Jakarta Sans', sans-serif;
  --font-family-heading: 'Outfit', sans-serif;
}

6. Patient & Admin Portals

The template includes complete, distinct dashboards for both patients and staff:

  • Patient Portal (/patient/): Patients can view upcoming sessions, watch prescribed HD exercise videos, check off daily routines, review pain level progression, and download printable medical receipts.
  • Admin Dashboard (/admin/): Clinic staff can manage patients, schedule master rooms and calendars, add new services, track insurance claims, and publish blog articles.

Use the quick autofill buttons on login.html to test both portals instantly.

7. Chart.js Customization

Charts are configured in assets/js/charts.js and listen for the global themeChanged event to dynamically re-style axes, ticks, and legend colors when switching between dark and light modes.
